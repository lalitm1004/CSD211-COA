# 2048 - Left Move
Implements 2048 in MARS MIPS.

## Input
- Each line in the text file must have at exactly 4 entries
- The text file must have exactly 4 lines
- Each entry must end with a comma `,`
- Each line must end with a comma `,`
- There must be no whitespace throughout the text file
Example:
```
0,4,0,4,
2,2,2,2,
4,2,2,8,
2,0,0,2,
```

## Usage
- Simply assemble and run
- enter 1 for performing a left shift
- enter 0 for exiting
- exits automatically when no more merges are possible
